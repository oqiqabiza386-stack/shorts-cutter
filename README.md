# ✂️ Shorts Cutter — ফ্রি, আনলিমিটেড, অফলাইন PWA

কোনো সার্ভার, ক্রেডিট, লিমিট বা সাবস্ক্রিপশন নেই। সব প্রসেসিং আপনার ফোনের Chrome-এই হয়।

## ফাইল
`index.html` `app.js` `style.css` `manifest.json` `sw.js` `icon-192.png` `icon-512.png` `build-apk.yml`

## ১. চালানোর উপায় (Termux)
PWA/Service Worker চালাতে `https` বা `localhost` লাগে (সরাসরি ফাইল খুললে হবে না)।

```bash
pkg update -y && pkg install -y python
cd ~/shorts-cutter        # ফোল্ডারটি যেখানে রেখেছেন
python -m http.server 8080
```
Chrome-এ খুলুন: `http://localhost:8080` → মেনু (⋮) → **Install app / Add to Home screen**।
একবার ইনস্টল হলে ইন্টারনেট ছাড়াই চলবে।

Termux না চাইলে: ফোল্ডারটি GitHub Pages / Netlify / Cloudflare Pages-এ (ফ্রি, HTTPS) আপলোড করুন।

## ২. ব্যবহার
1. **ভিডিও বাছুন** → ফোনের ফাইল (লিংক শুধু সরাসরি .mp4 ও CORS-সক্ষম হলে)।
2. প্লেয়ারে সময় ঠিক করে **[ শুরু সেট** ও **শেষ সেট ]** চাপুন → **ক্লিপ যোগ**। যত খুশি ক্লিপ।
3. ভিডিও চলার সময় ভাসমান **🔖** চাপলে হুক মার্ক হয়; "আগে/পরে" সেকেন্ড দিয়ে মার্কার → ক্লিপ।
4. (ঐচ্ছিক) SRT/VTT/টাইমস্ট্যাম্পসহ TXT দিন বা Groq key দিয়ে ট্রান্সক্রাইব করুন → ৮টি সেরা হুক-উইন্ডো দেখাবে।
5. রেশিও (9:16 / অরিজিনাল / 1:1 / 4:5 / 16:9), কোয়ালিটি, ফিট (ক্রপ / ব্লার / কালো বার), ফ্রেম পজিশন ঠিক করুন → **এক্সপোর্ট**।
6. রেজাল্টে **সেভ** বা **শেয়ার** (সরাসরি WhatsApp/YouTube Shorts/Instagram-এ)।

ক্লিপ ও মার্কার স্বয়ংক্রিয়ভাবে সেভ থাকে (একই ভিডিও আবার খুললে ফিরে আসে)।

## ৩. ফোনের মেমোরি/ব্যাটারি সামলানো
- এক্সপোর্ট রিয়েল-টাইমে হয় (৩০ সেকেন্ডের ক্লিপ ≈ ৩০ সেকেন্ড)। এ সময় স্ক্রিন চালু ও ট্যাব সামনে রাখুন (অ্যাপ Wake Lock চায়)।
- ক্লিপ একটার পর একটা এক্সপোর্ট হয়, তাই RAM-এ একসাথে একটাই থাকে।
- **720** কোয়ালিটি ও **30fps** ডিফল্ট — ব্যাটারি/তাপ কম। ধীর ফোনে 540 নিন।
- আউটপুট RAM-এ জমে। ৫ মিনিটের বেশি ক্লিপে ~১০০MB+ লাগতে পারে; লম্বা ক্লিপ বা দ্রুত কাজের জন্য **Termux স্ক্রিপ্ট** ব্যবহার করুন।
- Chrome নতুন হলে MP4 (H.264), নইলে WebM আউটপুট আসে।

## ৪. Termux + ffmpeg (দ্রুত পদ্ধতি, ইউটিউব লিংকসহ)
```bash
pkg install -y ffmpeg yt-dlp && termux-setup-storage
```
অ্যাপের নিচে **"Termux স্ক্রিপ্ট"** অংশে ফাইলের নাম (ও চাইলে ইউটিউব লিংক) দিয়ে **স্ক্রিপ্ট তৈরি** → **কপি** → Termux-এ পেস্ট করুন। আপনার ক্লিপ ও সেটিংস অনুযায়ী `yt-dlp` ও `ffmpeg` কমান্ড তৈরি হবে; আউটপুট `Movies/shorts` ফোল্ডারে।

## ৫. APK বানানোর উপায়

### (ক) সবচেয়ে সহজ: Chrome থেকে ইনস্টল
Chrome → ⋮ → **Install app**। এটি আসলে অ্যাপের মতোই চলে, সব ফিচার (সেভ/শেয়ার) নির্ভরযোগ্য।

### (খ) PWABuilder দিয়ে APK (প্রস্তাবিত, Chrome ইঞ্জিন ব্যবহার করে)
1. ফোল্ডার GitHub Pages-এ হোস্ট করুন (ফ্রি HTTPS লিংক পাবেন)।
2. [pwabuilder.com](https://www.pwabuilder.com) এ লিংক দিন → **Package for stores → Android** → APK ডাউনলোড।
3. APK ফোনে ইনস্টল করুন (Unknown sources অনুমতি দিন)।

### (গ) GitHub Actions (ফোন থেকেই, কম্পিউটার ছাড়া)
1. GitHub-এ নতুন রিপো বানিয়ে সব ফাইল আপলোড করুন।
2. `build-apk.yml` ফাইলটি `.github/workflows/build-apk.yml` পাথে রাখুন।
3. **Actions → Build APK → Run workflow**। ৫–১০ মিনিট পর **Artifacts** থেকে `app-debug.apk` নামান।

> ⚠️ (গ) পদ্ধতির APK Android WebView ব্যবহার করে; এতে ব্লব ফাইল "সেভ" বা "শেয়ার" কিছু ফোনে কাজ নাও করতে পারে। সেক্ষেত্রে (ক) বা (খ) ব্যবহার করুন।

## ৬. সীমাবদ্ধতা (স্পষ্টভাবে)
- ইউটিউব লিংক ব্রাউজারে সরাসরি প্রসেস হয় না → Termux `yt-dlp` দিয়ে নামান।
- এক্সপোর্ট রিয়েল-টাইম; ফোন লক বা ট্যাব ব্যাকগ্রাউন্ডে গেলে থেমে যেতে পারে।
- অডিও/ভিডিও ফ্রেম-নির্ভুল কাট নয় (±০.১ সেকেন্ড)। ফ্রেম-নির্ভুলতা লাগলে ffmpeg স্ক্রিপ্ট।
- Groq ফ্রি টিয়ারের রেট লিমিট আছে (আপনার অ্যাকাউন্টের), অ্যাপের নয়। Groq ব্যবহার ঐচ্ছিক।
